# Air Learner 2.0

Desktop guitar learning app. Learn songs on an interactive fretboard.

## Download

[Download v1.0.0](https://github.com/rizzwixk/airlearner/releases/download/v1.0.0/Air.Learner.2.0.Setup.exe)

## Build

```
npm install
npm run build:exe
```

## Songs

Smoke on the Water, Seven Nation Army, Come As You Are, Nothing Else Matters, Hotel California, Sunshine of Your Love, Iron Man, Smells Like Teen Spirit, Wonderwall, Back in Black, Stairway to Heaven, Enter Sandman
